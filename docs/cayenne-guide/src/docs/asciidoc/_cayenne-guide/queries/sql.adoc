[[sqlquery]]
=== SQLQuery

SQL is very powerful and allows to manipulate data in ways that can not always be described as a graph of related entities.
Cayenne acknowledges this fact and provides a facility to execute SQL, sometimes allowing to map results back to
persistent objects. `SQLQuery` is a query that runs native SQL. Depending on the factory method used to create it, it
selects custom data in form of entities, separate columns, collection of `DataRow` or `Object[]`. The same query
executes any other SQL (e.g. updates, deletes, DDLs, etc.), with everything the SQL produced, such as update counts,
returned from `execute(..)` as a list of `QueryResult`.

Specific SQL may not portable across databases. A query can carry alternative "dialects" of their SQL, keyed by the
`DbAdapter` class of the database they apply to. When the query runs, Cayenne picks the dialect matching the adapter of
the target `DataNode`, falling back to the default SQL when there is none. Just like the default SQL can be extended with `append(..)`, a
dialect can be built up incrementally with `dialectAppend(..)`:
